## 详细操作指南

### 第一步：注册 GitHub 账号（5 分钟）

GitHub 就像是一个 \&\#34;网络硬盘\&\#34;，我们的博客所有文件都存在这里。

**操作步骤：**

1. 打开浏览器，访问：[https://github\.com](https://github.com)

    【截图位置】GitHub 首页截图，显示右上角的 Sign up 按钮

2. 点击右上角的 **Sign up**（注册）按钮

3. 填写以下信息：

    - **Email address**：填你的邮箱

    - **Password**：设一个密码（8 位以上，包含字母和数字）

    - **Username**：填一个英文用户名（**非常重要！** 这会成为你博客网址的一部分）

    【截图位置】注册表单填写界面，重点圈出 Username 输入框

    > 💡 用户名建议：用拼音或英文，简短好记，避免特殊符号。
    > 比如填 `teacherwang`，你的博客地址就是 `teacherwang\.github\.io`
    > 
    > 

4. 完成人机验证（拼图或点击验证）

5. 点击 **Create account**（创建账号）

6. 去邮箱查收验证邮件，点击邮件里的验证链接

    【截图位置】邮箱验证成功的页面截图

**完成标准：** 成功登录 GitHub，能看到你的个人主页。

---

### 第二步：删除旧仓库 \+ Fork Chirpy 模板（5 分钟）

我们不用从零开始写博客，直接用一个现成的漂亮模板 ——Chirpy。

> 💡 如果你是第一次操作，没有旧仓库，可以直接跳到 \&\#34;用模板创建新仓库\&\#34; 部分。
> 
> 

#### 2\.1 删除旧仓库（如果有）

如果之前创建过同名仓库，需要先删掉：

1. 打开你的旧仓库页面

2. 点击页面顶部菜单栏最右边的 **Settings**（设置）

    【截图位置】仓库顶部菜单栏，圈出 Settings 按钮

3. 页面往下拉到最底部，找到红色区域 **Danger Zone**

    【截图位置】Danger Zone 红色区域，圈出 Delete 按钮

4. 点击 **Delete this repository**（删除此仓库）

5. 弹出确认框，按提示输入仓库全名（比如 `yourname/yourname\.github\.io`）

6. 点击红色确认按钮完成删除

#### 2\.2 用模板创建新仓库

1. 在浏览器新标签页打开：[https://github\.com/cotes2020/chirpy\-starter](https://github.com/cotes2020/chirpy-starter)

    【截图位置】Chirpy 模板主页，圈出绿色的 Use this template 按钮

2. 点击绿色按钮 **Use this template**

3. 在下拉菜单中点击 **Create a new repository**

4. 在 **Repository name**（仓库名称）输入框中填入：

    ```Plain Text
    你的用户名.github.io
    ```

    ⚠️ **必须和你的用户名完全一致，一个字母都不能错！**

    【截图位置】创建仓库页面，圈出 Repository name 输入框

5. 可见性选 **Public**（默认就是，不用改）

6. 拉到页面底部，点击绿色按钮 **Create repository**

    【截图位置】创建成功的仓库页面，能看到很多文件（config\.yml、posts 等）

---

### 第三步：开启 GitHub Pages 自动部署（3 分钟）

现在需要告诉 GitHub：\&\#34;请把这个仓库发布成网站！\&\#34;

1. 点击顶部菜单的 **Settings**（设置）

    【截图位置】仓库顶部菜单栏，圈出 Settings

2. 在左侧边栏找到 **Pages**，点击进去

    【截图位置】左侧边栏，圈出 Pages 选项

3. 找到 **Build and deployment** 部分：

    - Source 下拉菜单，选择 **GitHub Actions**

    - ❌ 不要选 Deploy from a branch！

    【截图位置】Build and deployment 区域，圈出 Source 下拉菜单并标注选 GitHub Actions

4. 选完之后页面会自动保存，不需要点任何确认按钮

5. 等待约 1 分钟，页面顶部会显示：

    ```Plain Text
    Your site is live at https://你的用户名.github.io/
    ```

    【截图位置】部署成功提示，圈出蓝色的网站链接

6. 点击蓝色链接，就能看到你的博客了！

    【截图位置】刚部署好的博客默认首页截图

> 💡 大白话解释两种部署方式的区别：
> 
> - Deploy from a branch = 把食材直接端上桌（生的）
> 
> - GitHub Actions = 把食材先自动做熟，再端上桌
> 
> Chirpy 模板必须用 GitHub Actions，否则博客打开是空白的！
> 
>

### 第四步：修改博客基本信息（config\.yml 配置）（10 分钟）

现在博客内容还是默认的，我们来改成你自己的信息。所有设置都在一个叫 `\_config\.yml` 的文件里。

1. 回到仓库页面

2. 在文件列表里找到 `\_config\.yml`，点击它

    【截图位置】文件列表，圈出 \_config\.yml 文件

3. 进入文件后，点击右上角的铅笔图标（Edit this file）

    【截图位置】文件查看页面，圈出右上角的铅笔编辑图标

4. 找到以下几行，逐一修改：

    |    原内容|    修改成|    说明|
    |---|---|---|
    |    `title: Chirpy`|    `title: 你的博客名称`|    比如：在野哇|
    |    `tagline: A text\-focused Jekyll theme`|    `tagline: 你的一句话简介`|    比如：观物察己，感时应物|
    |    `url:`|    `url: \&\#34;https://你的用户名\.github\.io\&\#34;`|    填你的完整博客地址|
    |    `name: your full name`|    `name: 你的名字`|    页脚显示的名字|

    【截图位置】config\.yml 编辑界面，圈出需要修改的这几行

5. 修改完成后，拉到页面最底部

6. 看到 **Commit changes** 绿色按钮，直接点击

    【截图位置】页面底部的 Commit changes 区域，圈出绿色按钮

7. 弹出小窗口，再点一次 **Commit changes** 确认

8. 等待约 1\~2 分钟，刷新你的博客页面看效果

    【截图位置】修改后的博客首页，显示你的博客名称和简介

### 第五步：发布第一篇文章（Markdown 语法入门）（5 分钟）

Chirpy 博客的文章都放在 `\_posts` 文件夹里。

1. 回到仓库页面，点击 `\_posts` 文件夹

    【截图位置】文件列表，圈出 \_posts 文件夹

2. 点击右上角 **Add file** → **Create new file**

    【截图位置】右上角，圈出 Add file 按钮和下拉菜单

3. 在顶部文件名输入框填入：

    ```Plain Text
    2026-05-03-hello-world.md
    ```

    ⚠️ 文件名格式必须是：`年\-月\-日\-文章标题\.md`

    【截图位置】文件名输入框，标注正确的格式

4. 在下方空白编辑区域，粘贴以下内容：

    ```markdown
    ---
    title: 你好，世界
    date: 2026-05-03 10:00:00 +0800
    categories: [随笔]
    tags: [第一篇]
    ---
    
    这是我的第一篇博客文章。
    
    在野哇，观物察己，感时应物。
    
    从今天起，记录所见所思所感。
    ```

    【截图位置】编辑区域，显示完整的文章内容

5. 点右上角 **Commit changes**，弹窗里再点一次确认

6. 等待约 1\~2 分钟后刷新博客，第一篇文章就会出现！

    【截图位置】博客首页显示新发布的文章

### 第七步：上传头像（3 分钟）

给博客左上角的空白圆圈换上你自己的头像。

#### 7\.1 准备头像图片

- 格式：JPG 或 PNG 均可

- 建议尺寸：正方形，至少 200×200 像素

- 文件名改成简单的英文，比如 `avatar\.jpg`

#### 7\.2 上传图片

1. 打开仓库，点击 `assets` 文件夹

2. 点击右上角 **Add file** → **Upload files**

    【截图位置】Upload files 选项

3. 把你的头像图片拖进去或点击选择文件

    【截图位置】文件上传区域，显示已选择的 avatar\.jpg

4. 确认文件名显示为 `avatar\.jpg`，然后点 **Commit changes** 保存

#### 7\.3 设置头像路径

1. 回到仓库根目录，打开 `\_config\.yml`

2. 找到这一行：`avatar:`

3. 改成：`avatar: /assets/avatar\.jpg`

    【截图位置】config\.yml 中 avatar 配置行

4. **Commit changes** 保存

5. 等待 1\~2 分钟后刷新博客，左上角就会显示你的头像了！

    【截图位置】博客左上角显示头像的效果

### 第八步：添加文章封面图（3 分钟）

给文章加上封面图，首页列表看起来更丰富好看。

#### 方法一：用网络图片链接（最简单）

1. 在文章头部信息里加上 `image` 字段：

    ```yaml
    ---
    title: 你好，世界
    date: 2026-05-03 10:00:00 +0800
    categories: [随笔]
    tags: [第一篇]
    image:
      path: 图片网址
      alt: 图片描述文字
    ---
    ```

2. 去哪里找免费图片？

    - [https://unsplash\.com](https://unsplash.com) \- 高质量摄影图

    - [https://www\.pexels\.com/zh\-cn](https://www.pexels.com/zh-cn) \- 中文界面，好找图

3. 找到喜欢的图片后，右键 → 复制图片地址，粘贴到 `path:` 后面即可

#### 方法二：上传图片到仓库（更稳定）

1. 把图片上传到 `assets/` 文件夹，比如取名 `cover1\.jpg`

2. 在文章头部填：

    ```yaml
    image:
      path: /assets/cover1.jpg
      alt: 图片描述
    ```

【截图位置】添加了封面图的文章列表效果

### 第九步：开启 Giscus 评论功能（5 分钟）

让读者可以在文章下面留言评论，增加互动。

Giscus 的优点：

- 完全免费

- 基于 GitHub，不需要额外注册账号

- 评论数据存在你自己的仓库里，永久保留

#### 9\.1 开启仓库的 Discussions 功能

1. 打开仓库 **Settings**（设置）

2. 左侧找 General，往下找到 Features 部分

3. 勾选 **Discussions**

    【截图位置】Features 区域，圈出 Discussions 勾选框

4. 页面会自动保存

#### 9\.2 安装 Giscus 应用

1. 打开：[https://github\.com/apps/giscus](https://github.com/apps/giscus)

2. 点击 **Install**

3. 选择 **Only select repositories**，选中你的博客仓库

4. 点 **Install** 确认

#### 9\.3 生成配置代码

1. 打开：[https://giscus\.app/zh\-CN](https://giscus.app/zh-CN)

2. 按以下填写：

    - 仓库：`你的用户名/你的用户名\.github\.io`

    - Discussion 分类：选 **Announcements**

    - 其他选项默认即可

3. 填完后页面下方会自动生成配置，找到这两个值：

    - `data\-repo\-id`

    - `data\-category\-id`

    【截图位置】Giscus 配置页面生成的代码段，圈出需要的两个 ID 值

#### 9\.4 填入配置文件

1. 打开 `\_config\.yml`

2. 找到 comments 部分，改成：

    ```yaml
    comments:
      provider: giscus
    
    giscus:
      repo: 你的用户名/你的用户名.github.io
      repo_id: 刚才拿到的 repo_id
      category: Announcements
      category_id: 刚才拿到的 category_id
      mapping: pathname
      strict: 0
      input_position: bottom
      lang: zh-CN
      reactions_enabled: 1
    ```

    【截图位置】config\.yml 中完整的 comments 配置段

3. **Commit changes** 保存

4. 等 1\~2 分钟后打开任意一篇文章，拉到最底部，就能看到评论框了！

    【截图位置】文章底部显示的 Giscus 评论框

## 常见问题 FAQ

### Q1：仓库名必须叫 `用户名\.github\.io` 吗？

A：这是 GitHub Pages 的 \&\#34;主站\&\#34; 模式，每个账号只能有 1 个，地址最干净。
以后想再建其他博客，可以用 \&\#34;项目站\&\#34; 模式，仓库名随便取，地址是 `用户名\.github\.io/仓库名`。

|类型|仓库名要求|访问地址|数量限制|
|---|---|---|---|
|主站|必须叫 `用户名\.github\.io`|`用户名\.github\.io`|1 个|
|项目站|随便取名|`用户名\.github\.io/仓库名`|无限个|

### Q2：仓库容量够吗？能放多少图片？

A：GitHub 仓库容量说明：

- 仓库总大小：建议不超过 1GB，软上限 5GB

- 单个文件：不超过 100MB

- 每月流量：100GB（对个人博客完全够用）

一张普通博客封面图压缩后约 200\\500KB，1GB 空间可以存 2000\\5000 张图片。
按每周发一篇文章、每篇一张封面图来算：1000 ÷ 52 = 约 19 年才能用完。

### Q3：怎么管理和删除评论？

A：Giscus 的评论实际上存储在你仓库的 Discussions 里：

1. 打开仓库页面，点击顶部菜单的 **Discussions** 标签

2. 每篇文章对应一个 Discussion 帖子，所有评论都在里面

|操作|方法|
|---|---|
|删除某条评论|点评论右上角 `⋯` → Delete|
|隐藏某条评论|点评论右上角 `⋯` → Hide|
|锁定评论|进入对应 Discussion → 右侧 Lock conversation|
|删除整篇评论区|直接删除对应的 Discussion|

只有你（仓库管理员）才能删除评论，读者只能删除自己发的。

### Q4：修改后博客没更新怎么办？

A：修改后需要等待 1\~2 分钟让 GitHub 自动重新部署，然后按 `Ctrl\+F5` 强制刷新浏览器缓存。

如果还是没更新：

1. 去仓库的 Actions 页面看部署是否成功

2. 检查 config\.yml 格式是否正确（冒号后面要有空格）

3. 确认文件名和路径没有写错

### Q5：文章发布后能修改吗？

A：完全可以！随时回到 `\_posts` 文件夹，点击对应文章的铅笔图标编辑，保存后会自动更新。
